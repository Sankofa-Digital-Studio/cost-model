# Security Policy

## Supported Versions

We provide security updates and formula bug fixes for the current active release line:

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |
| `dev`            | :white_check_mark: |
| `< 1.0.0`        | :x:                |

---

## Reporting a Vulnerability

The security of our models, confidential contract specifications, client pricing structures, and engineering automation scripts is taken very seriously.

If you discover a security vulnerability, sensitive data exposure, or formula tampering risk:

1. **Do not create a public GitHub issue.**
2. Send an encrypted email or private vulnerability advisory to **security@sankofadigital.co.za**.
3. Include:
   - Description of the issue and affected files/scripts.
   - Proof of concept or reproduction steps.
   - Any potential impact on client pricing confidentiality or formula integrity.

### Response SLA
- **Initial Acknowledgement**: Within 24 hours.
- **Triage & Assessment**: Within 72 hours.
- **Remediation / Patch**: Deployed to `main` as quickly as possible with priority communication to affected commercial stakeholders.
