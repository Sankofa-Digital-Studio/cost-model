# Support Guidelines

## Getting Help

If you need help using or extending the **Mining & Heavy Industrial Decommissioning, Environmental Rehabilitation & Costing Automation Engine**, here are the recommended channels:

### 1. Documentation
Before opening an issue or contacting support, check the following documentation:
- [README.md](README.md) for quickstart, usage, and financial waterfall documentation.
- [CONTRIBUTING.md](CONTRIBUTING.md) for code conventions, OpenPyXL standards, and verification guidelines.
- Source specification documents: [`CAPM Tau Mine 10# Scope of work 1.docx`](CAPM%20Tau%20Mine%2010%23%20Scope%20of%20work%201.docx).

### 2. GitHub Issues
- **Bug Reports**: If you encounter an OpenPyXL generation failure, incorrect formula evaluation, or `#REF!` error, submit a [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md).
- **Feature Requests**: If your project requires new specialized phase packages (e.g. tailings dam dredging, shaft dewatering, heavy crane rigging), submit a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md).

### 3. Commercial & Engineering Advisory
For commercial inquiries, specialized mining closure advisory, or tailored contractor rate modeling, please contact:
- **Engineering & Commercial Lead**: commercial@sankofadigital.co.za
- **Senatla Operations**: operations@senatlatrading.co.za
